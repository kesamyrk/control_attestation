## Часть B. Что выведет код

**21.**
```
{'a': 100, 'b': 2, 'c': 3}
3
```
Присваивание по существующему ключу меняет значение, порядок ключей не меняется.

**22.**
```
1
2
3
```

**23.**
```
{'x': 1, 'y': 2}
['z', 'y']
```
`list(d.keys())` - отдельный список, словарь не меняется.

**24.**
```
{'a': 1, 'new': 'value'}
```
Функция получает ссылку на тот же словарь и меняет его.

**25.**
```
{1, 2, 3, 4}
4
```
Повторное `add(2)` ничего не добавляет.

**26.**
```
{1, 2, 3, 4}
True
```
`b` и `a` - один и тот же объект.

**27.**
```
([1, 2, 99], [3, 4])
```
Сам кортеж не меняется, но список внутри него изменяемый.
