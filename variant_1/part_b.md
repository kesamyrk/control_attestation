## Часть B. Что выведет код

**21.**
```
[1, 2, 3, 4, 5]
[100, 3, 4]
```
Срез создаёт новый список, исходный не меняется.

**22.**
```
None
[1, 2, 3]
```
`sort()` сортирует на месте и возвращает `None`.

**23.**
```
[1, 2, 3]
[1, 2]
```
`a + [3]` создаёт новый список, `b` остаётся ссылкой на старый.

**24.**
```
[1, 2, 3]
[1, 2, 3]
```
`+=` меняет тот же самый список, на который ссылаются и `a`, и `b`.

**25.**
```
[1, 2, 3]
[1, 2, 3, 99]
```
Внутри функции `lst + [99]` создаёт новый список, оригинал не меняется.

**26.**
```
{'a': 1, 'b': 2}
[('x', 100), ('b', 2)]
```
`list(data.items())` - отдельный список, словарь не меняется.

**27.**
```
[[100, 2], [3, 4]]
[[100, 2], [3, 4]]
```
`copy()` копирует только внешний список, вложенные списки общие.
